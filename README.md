## 영천고 급식

영천고등학교 급식 정보를 조회하고 메뉴별로 별점과 후기를 남길 수 있는 웹페이지입니다.

### 이번 개편 (UI/기능 전면 개편)
- 전체 UI 리디자인 (카드형 레이아웃, 라이트/다크 테마 개선)
- 메뉴 검색, 즐겨찾기 메뉴 표시/필터
- 영양정보·원산지정보 모달 추가
- 알레르기 필터에 "강조/숨기기" 모드 추가
- 내가 남긴 리뷰 표시 및 삭제 기능
- 주간 급식 패널 이전/다음 주 이동
- 오늘의 메뉴 공유(클립보드 복사) 기능
- 리뷰 텍스트 등 사용자 입력 이스케이프 처리로 XSS 방지

NEIS Open API 및 Firebase 연동 방식은 기존과 동일하게 유지됩니다.
